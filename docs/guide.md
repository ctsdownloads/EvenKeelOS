# EvenKeelOS guide

How to do things on EvenKeelOS, step by step.

## New to EvenKeelOS?

Coming from Windows: where things are, and what's different.

### Where things are

1. Start menu: with the Windows-style layout, the sailboat button at the bottom left. With the standard layout, press the Windows key.
2. Control Panel: Settings, for Wi-Fi, screens, sound, printers and accounts. System Tools, for updates, apps and fixes.
3. File Explorer: Files.
4. Task Manager: Resources. Find it in the start menu.
5. Word, Excel and PowerPoint: LibreOffice Writer, Calc and Impress. They open and save Office files.
6. Notepad: Text Editor. Photos: Image Viewer. Videos: Celluloid. Music: Lollypop. PDFs: Papers.

### What's different

1. Windows programs (.exe and .msi) don't run here. Open one anyway: System Tools tells you the version for EvenKeelOS, or a replacement when there is one, and installs it.
2. Updates install on their own. If one stops the computer starting properly, it goes back to the version before by itself and tells you.
3. The system itself can't be changed by apps or by mistake. Each update replaces it whole.
4. Every network is Home, Work or a Public place. A new one is a Public place, where nothing can reach your computer.

## The desktop

The start menu, windows, the menu at the end of the bar, notifications, screenshots and shortcuts.

### Open an app

1. With the Windows-style layout: click the sailboat button at the bottom left, then click the app, or start typing its name and press Enter.
2. With the standard layout: press the Windows key, start typing the app's name, and press Enter. Or press Windows key + A to see every app.

### Change the layout

1. Open System Tools, Make it yours.
2. Pick Windows-style (a bar at the bottom and a start menu) or Standard (a bar at the top and a dock).
3. Log out and back in to see it.

### Move and arrange windows

1. The buttons at a window's top right minimize, maximize and close it, as on Windows.
2. Drag a window to the top of the screen to fill the screen. Drag it to the left or right edge to fill that half.
3. Or use the keyboard: Windows key + Up fills the screen, Windows key + Left or Right fills a half, and Windows key + H minimizes.
4. Alt+Tab switches between apps. Alt and the key above Tab switches between windows of the same app.

### Wi-Fi, sound, brightness and power

1. Click the icons at the end of the bar: the bottom right with the Windows-style layout, the top right with the standard one. Or press Windows key + S.
2. The menu that opens has Wi-Fi, Bluetooth, the sound volume, the screen brightness, the power mode, dark style and night light.
3. The power button in that menu has Suspend, Restart, Power Off and Log Out.
4. Windows key + L locks the screen.

### Notifications

1. Click the clock to see your notifications and the calendar. Or press Windows key + V.
2. Do Not Disturb, in the same place, keeps notifications quiet until you turn it off.
3. To choose which apps can notify you: Settings, Notifications.

### Take a screenshot or record the screen

1. Press Print Screen. Pick the whole screen, a window, or drag over an area, then click the round button.
2. The picture is copied, ready to paste, and saved in Pictures, Screenshots.
3. To record a video instead, click the video camera icon in the same tool before you start. Recordings go to Videos, Screencasts.
4. Shift+Print Screen takes a picture of the whole screen straight away.

## Files

Your folders, USB drives, the trash, searching, zip files and sharing with other computers.

### Find your files

1. Open Files from the start menu or the dock. It opens on your home folder.
2. Documents, Downloads, Pictures, Music and Videos are there, as on Windows.
3. Click the magnifying glass, or press Ctrl+F, and type to search this folder and the folders in it.
4. Ctrl+H shows hidden files and folders, whose names start with a dot. Most hold app settings: leave them alone.

### USB drives and memory cards

1. Plug it in. It shows in the left side of Files.
2. Copy files by dragging them onto it, or with Ctrl+C and Ctrl+V.
3. Before you unplug it, click the eject button next to its name, and wait until it's gone from the list.

### Delete a file, or get it back

1. Select it and press Delete. It goes to the Trash.
2. To get it back: open Trash in the left side of Files, right-click the file, and choose Restore From Trash.
3. To free the space for good: open Trash and click Empty.

### Zip files

1. To make one: select the files, right-click, choose Compress, give it a name, and click Create.
2. To open one: right-click it and choose Extract. The files go in a folder next to it.

### Choose which app opens a file

1. Right-click the file and choose Open With.
2. Pick the app. To use it every time for that kind of file, turn on Always use for this file type first.
3. For the web browser, email, calendar, music, videos and photos: Settings, Apps, Default Apps.

### Open your folders from another computer at home

1. Open System Tools, Shared folders.
2. Set a sharing password, then turn on Share folders on Home networks.
3. Click Add a folder and pick it. It starts as Read only: change it to Read and write if the other computer should save there too.
4. On a Windows PC: File Explorer, Network. The Windows PC's own network must be set to Private.
5. On a Mac: Finder, Network. On another Linux computer: Files, Other Locations.
6. Open this computer, type your user name and the sharing password, and the folders are there.

## Apps

Getting apps, Windows programs, package files, removing apps, default apps, Zoom, VPNs and codecs.

### Get an app

1. Open Bazaar, the app store, from the start menu or the dock.
2. Search for the app, open it, and click Install.
3. Apps from Bazaar update on their own. Remove them in Bazaar too.

### A Windows program you downloaded (.exe or .msi)

1. Open the file, or drop it on System Tools, Apps.
2. It tells you whether there's a version for EvenKeelOS, or a replacement that does the same job.
3. Click Install, and it installs that instead.

### An app that comes as a .rpm or .deb file

1. Open the file, or use Install a package file in System Tools, Apps.
2. It says first whether the app keeps itself updated, then installs it.
3. Some, like printer drivers, are added to the system: they're ready after the next restart.

### Remove an app

1. Apps from Bazaar: open Bazaar and remove it there.
2. Apps from a file, Get a VPN or a Windows program: System Tools, Apps, Remove apps.

### Start an app when you log in

1. Apps from Bazaar have this setting inside the app.
2. Apps from a file: open System Tools, Apps, Start apps at login, and pick the app. Picking it again stops it.

### Default apps

1. Open Settings, Apps, Default Apps.
2. Pick the app for the web, mail, calendar, music, videos and photos.

### Zoom meetings

1. Click the meeting link you were sent.
2. The first time, choose Install Chrome or Use the usual browser. The meeting opens in Zoom's web version.
3. To be asked again: System Tools, Apps, Zoom meetings.

### A VPN

1. Open System Tools, Apps, Get a VPN.
2. Pick Mullvad, Proton, IVPN or NordVPN. It's added from that company's own download source, and kept up to date.
3. Restart, then sign in with your account from that company.

### Media codecs, for some videos

1. Open System Tools, Apps, Media codecs.
2. Pick what you need. It explains each choice.

### A broken app box

1. Some apps from .rpm or .deb files run in an app box. If one stops starting, open System Tools, Apps, Repair app boxes.
2. Pick the box. It's set up again, with its apps. Your files aren't touched.
