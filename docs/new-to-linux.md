# New to Linux?

Most of what you did on Windows works the same way here. This is where things are, and what's different. It's in System Tools, Get help, any time.

## Where things are

- Start menu: with the Windows-style layout, the sailboat button at the bottom left. With the standard layout, press the Windows key, or open Show Apps in the dock.
- Control Panel: Settings for Wi-Fi, screens, sound, printers and accounts. System Tools for updates, apps and fixes.
- File Explorer: Files.
- Task Manager: Resources. Find it in the start menu, or Show Apps.
- Word, Excel and PowerPoint: LibreOffice Writer, Calc and Impress. They open and save Office files.
- Notepad: Text Editor. Photos: Image Viewer. Videos: Celluloid. Music: Lollypop. PDFs: Papers.

## Getting apps

- Most apps come from Bazaar, the app store. Apps from there update on their own.
- A Windows program (.exe or .msi) can't run here. Open it anyway: System Tools tells you its Linux version, or a replacement when there is one, and installs it.
- An app that comes as a .rpm or .deb file installs when you open the file.
- Remove apps in System Tools, Apps.

## Updates

- Updates install on their own, for the system and your apps. System updates start at your next restart.
- If an update stops the computer starting properly, it goes back to the version before by itself and tells you.
- If something stopped working after an update, Undo the last update goes back one version. Your files and apps aren't touched.

## Your files

- Your Documents, Downloads, Pictures, Music and Videos folders are in your home folder, in Files.
- USB drives show in the left side of Files. Eject them there before you unplug them.
- To open your folders from other computers at home, use Shared folders.

## Networks and printers

- Every network is Home, Work or a Public place. A new one is a Public place, where nothing can reach your computer.
- Printers: Settings, Printers. Many printers are found and work with no driver to install. If your printer's maker gives you a driver file, open it like any app file.

## What works differently

- Copy and paste, right-click and the window buttons work as on Windows. Alt+Tab switches between apps.
- Print Screen opens the screenshot tool, to pick the whole screen, a window or an area.
- The system itself is read-only: apps and mistakes can't change it. Each update replaces it whole.
- If you want a virus scanner, ClamUI is in Bazaar.

## Getting help

- Something not right? Save problem details makes one file of recent errors to send to your helper.
